    1. 小王搬入新居后，在厨房安装了一台电热水壶。壶身铭牌上标注“220V 2200W”，而家中电能表标注“220V 10(40)A”。小王想从电工学角度分析一下这个电热水壶的工作参数：
    
    (1) 该电热水壶正常工作时通过的电流是多少?
    
    (2) 电热水壶发热管的电阻值是多少?
    
    (3) 如果用电高峰期实际供电电压降至200V，电热水壶的实际功率会变为多少?(假设电阻不随温度变化)
    </Wenben>
    <Ansinput katex />
    <Jiexi>
    <h3>(1) $I = \frac{P}{U} = I = \frac{2200}{220} = 10A$</h3>
    
    根据电功率的基本公式 $P = UI$，其中P为电功率(单位：W)，U为电压(单位：V)，I为电流(单位：A)。该公式表达了电功率与电压、电流三者之间的基本关系，是电工学中最常用的公式之一。
    
    由题意，电热水壶铭牌标注额定功率 $P = 2200W$，额定电压 $U = 220V$，均为正常工作条件下的参数。将已知数据代入公式，进行变形求解电流： $I = \frac{P}{U} = I = \frac{2200}{220} = 10A$ 
    
    因此，电热水壶正常工作时通过的电流为 10A。(评分：写出公式 $P=UI$ 得1分，正确代入数据得1分，计算结果正确得1分。本小题共3分。)
    
    <h3>(2) $R = \frac{U}{I} = \frac{220}{10} = 22Ω$</h3>
    
    根据欧姆定律 $U = IR$，其中U为导体两端电压，I为通过导体的电流，R为导体的电阻。
    
    该定律表明，在温度不变时，金属导体的电阻为定值，电压与电流成正比。将欧姆定律变形，求解电阻： $R = \frac{U}{I} = \frac{220}{10} = 22Ω$
    
    此结果的物理意义：电热水壶发热管的电阻为22Ω，这是一个较低的阻值，正是因为电阻小、电流大，才能在短时间内产生足够的热量来加热水。(评分：写出欧姆定律公式得1分，正确代入数据得1分，计算结果正确且单位正确得1分。本小题共3分。)
    
    <h3>(3) $P' = \frac{{U'}^2}{R} = \frac{200^2}{22} = \frac{40000}{22} ≈ 1818.2W$</h3>
    
    题目假设电阻不随温度变化，即电阻仍为 $R = 22Ω$ 不变。当用电高峰期供电电压降至 $U' = 200V$ 时，由于电阻不变，可根据电功率的另一种表达形式 $P = \frac{U^2}{R}$ 进行计算。
    
    此公式由 $P = UI$ 和 $I = \frac{U}{R}$ 联立推导而得：将 $I = \frac{U}{R}$ 代入 $P = UI$，得 $P = U(\frac{U}{R}) = \frac{U^2}{R}$。
    
    代入数据计算实际功率： $P' = \frac{{U'}^2}{R} = \frac{200^2}{22} = \frac{40000}{22} ≈ 1818.2W$
    
    由此可见，当电压从220V降至200V(下降了约9.1%)，功率从2200W降至1818.2W(下降了约17.4%)，说明功率与电压的平方成正比，电压的微小下降会导致功率更大幅度地降低。(评分：说明电阻不变假设得1分，写出 $P = \frac{U^2}{R}$ 公式得1分，正确代入数据得1分，计算结果正确得1分。本小题共4分。)
    </Jiexi>

    <h3>(1) $I = \frac{P}{U} = \frac{100}{220} ≈ 0.455A$</h3>
    
    吹冷风时，只有电动机工作，此时电吹风消耗的功率即为电动机功率 $P = 100W$ ，额定电压 $U = 220V$。
    
    由电功率公式 $P = UI$，变形求电流：$I = \frac{P}{U} = \frac{100}{220} ≈ 0.455A$
    
    因此，吹冷风时的工作电流约为0.455A。(评分：识别冷风时仅有电动机工作得1分，写出 $P = UI$ 并代入得1分，计算结果正确得1分。本小题共3分。)
    
    <h3>(2) $R = \frac{U^2}{P} = \frac{220^2}{1100} = \frac{48400}{1100} = 44Ω$</h3>
    
    吹热风时，电动机和电热丝并联同时工作。热风功率 = 电动机功率 + 电热丝功率，因此： $P_{电热丝} = P_{热风} - P_{电动机} = 1200 - 100 = 1100W$
    
    由于电热丝与电动机并联，两者都接在220V电源上，电热丝两端电压 $U = 220V$。由电功率公式 $P = \frac{U^2}{R}$，变形求电阻： $R = \frac{U^2}{P} = \frac{220^2}{1100} = \frac{48400}{1100} = 44Ω$
    
    因此，电热丝的电阻为44Ω。这个较低的电阻值使得通过电热丝的电流较大($I = \frac{220}{44} = 5A$)，从而产生大量焦耳热。(评分：计算电热丝功率得1分，说明并联电压关系得1分，写出 $P = \frac{U^2}{R}$ 并代入得1分，计算结果正确得1分。本小题共4分。)
    
    <h3>(3) $W = Pt = 1.2\times\frac{1}{3} = 0.4kWh = 0.4度$</h3>
    
    吹热风时总功率 $P = 1200W = 1.2kW$，工作时间 $t = 20$ 分钟。
    
    首先将时间换算为小时：$20分钟 = \frac{20}{60}小时 = \frac{1}{3}小时$ 由电能公式 $W = Pt = 1.2\times\frac{1}{3} = 0.4kWh = 0.4度$
    
    因此，吹热风20分钟消耗0.4度电。(评分：功率单位换算得1分，时间单位换算得1分，写出 $W = Pt$ 并计算正确得1分。本小题共3分。)

    3. 小明的手机电池容量为4000mAh，额定电压3.8V。他用一个输出规格为5V/2A的充电器给手机充电。假设充电过程中充电电流恒定为2A，从20%充到100%用时约1.5小时。
    
    (1) 充电器的输出功率是多少?
    
    (2) 电池实际储存的电能增加了多少?
    
    (3) 这次充电过程的能量转换效率约为多少?
    </Wenben>
    <Ansinput katex />
    <Jiexi>
    <h3>(1) $P = 5 × 2 = 10W$</h3>
    
    充电器的输出电压 $U = 5V$，输出电流 $I = 2A$。
    
    由电功率公式 $P = UI$ 得 $P = 5 × 2 = 10W$
    
    因此，充电器的输出功率为10W。(评分：写出 $P = UI$ 公式得1分，正确代入数据得1分，计算结果正确得1分。本小题共3分。)
    
    <h3>(2) $W = U × Q = 3.8 × 3.2 = 12.16Wh$</h3>
    
    电池容量为4000mAh，从20%充到100%，充入的电量占总容量的80%：$Q = 4000 × (100\% - 20\%) = 4000 × 80\% = 3200mAh = 3.2Ah$
    
    电池额定电压 $U = 3.8V$，储存的能量增加：$W = U × Q = 3.8 × 3.2 = 12.16Wh$
    
    注意：这里用电池额定电压3.8V而非充电器电压5V，因为我们要计算的是电池实际储存的化学能，而非充电器输出的电能。(评分：计算充入电量得1分，单位换算mAh→Ah得1分，写出 $W = U×Q$ 并代入正确得1分，结果正确得1分。本小题共4分。)
    
    <h3>(3) $η = \frac{W_{电池}}{W_总} = \frac{12.16}{15} ≈ 0.811 = 81.1\%$</h3>
    
    充电器在1.5小时内输出的总能量： $W_总 = P × t = 10 × 1.5 = 15Wh$
    
    能量转换效率定义为：有用能量(电池储存的能量)/ 总输入能量(充电器输出能量)：$η = \frac{W_{电池}}{W_总} = \frac{12.16}{15} ≈ 0.811 = 81.1\%$
    
    效率低于100%的原因包括：充电过程中的热损耗(电池内阻发热)、充电管理电路的损耗以及充电电压高于电池电压导致的能量差异。(评分：计算充电器输出总能量得1分，写出效率公式得1分，计算结果正确得1分。本小题共3分。)

    由电功率公式 $P = \frac{U^2}{R}$，变形求电阻： $R = \frac{U²}{P} = \frac{220²}{60} = \frac{48400}{60} ≈ 806.7Ω$ 电烙铁属于纯电阻用电器(将电能全部转化为热能)，因此可以使用 $P = \frac{U²}{R}$ 公式。

    电烙铁功率 $P = 60W$ ，工作时间 $t = 45 分钟 = 0.75小时$。
    
    方法一(用瓦时计算)：$W = P × t = 60 × 0.75 = 45Wh$
    
    方法二(用焦耳计算，需将时间换算为秒)：$t = 45 × 60 = 2700s$
    
    $W = P × t = 60 × 2700 = 162000J = 162kJ$
    
    两种方法等价，$1Wh = 3600J$，验证：$45 × 3600 = 162000J$ (评分：写出 $W = Pt$ 公式得1分，时间换算正确得1分，计算结果正确得1分。本小题共3分。)

    6. 某工厂车间有一台三相异步电动机，铭牌标注：额定功率7.5kW，额定电压380V，额定电流15A，功率因数 $cosφ=0.85$。

    (2) 电动机的效率是多少?

    <h3>(1) $P_入 = 1.732 × 380 × 15 × 0.85 ≈ 8397W ≈ 8.4kW$</h3>
    
    三相对称电路的有功功率公式为 $P = \sqrt 3 × U × I × cosφ$，其中 $\sqrt 3 ≈ 1.732$ 是三相电路的系数，U为线电压(380V)，I为线电流(15A)，$cosφ$ 为功率因数(0.85)。
    
    该公式的物理意义：在三相对称系统中，总有功功率等于3倍的相功率，经推导可简化为上述形式。
    
    功率因数 $cosφ$ 反映了电流与电压的相位差，$cosφ < 1$ 说明电动机是感性负载，存在无功功率。代入数据：$P_入 = 1.732 × 380 × 15 × 0.85 ≈ 8397W ≈ 8.4kW$
    
    因此，电动机的输入电功率约为8.4kW。(评分：写出三相功率公式得2分，正确代入数据得1分，计算结果正确得1分。本小题共4分。)
    
    <h3>(2) $η = \frac{P_出}{P_入} = \frac{7.5}{8.4} ≈ 0.893 = 89.3\%$</h3>
    
    电动机效率定义为输出机械功率与输入电功率之比：$η = \frac{P_出}{P_入} = \frac{7.5}{8.4} ≈ 0.893 = 89.3\%$
    
    差值 $P_损 = P_入 - P_出 = 8.4 - 7.5 = 0.9kW$ 为电动机的各种损耗(铜损、铁损、机械摩擦损耗等)。
    
    89.3%的效率在小型三相异步电动机中属于正常水平。(评分：写出效率定义得1分，正确代入计算得1分，结果正确得1分。本小题共3分。)
    
    <h3>(3) $W = P_入 × t × 天数 = 8.4 × 8 × 30 = 2016kWh = 2016度$</h3>
    
    每天运行 $t = 8小时$，每月30天。月消耗电能 $W = P_入 × t × 天数 = 8.4 × 8 × 30 = 2016kWh = 2016度$

    7. 冬天使用的一款电热毯有“高温”和“低温”两档，内部有两根相同的电热丝R1和R2(阻值均为110Ω)，通过一个开关切换连接方式。高温档时R1和R2并联，低温档时只有R1工作。

    26. 小陈在自家屋顶安装了一套分布式光伏发电系统，装机容量5kW。某日晴天，系统从上午9点到下午4点(共7小时)的平均输出功率为额定功率的60%。已知当地上网电价为0.42元/kWh，自用电价为0.52元/kWh。假设所发电量全部自用。
    
    (1) 该日发电总量是多少kWh?
    
    (2) 该日节省的电费是多少?
    
    (3) 如果该系统的投资成本为4万元，按此日均发电量计算，大约需要多少天回收投资成本?
    </Wenben>
    <Ansinput katex />
    <Jiexi>
    <h3>(1) $W = 3 × 7 = 21kWh$</h3>
    
    光伏系统的装机容量(额定功率)为5kW，但实际输出功率受光照条件影响。
    
    该日晴天平均输出功率为额定功率的60%：$P_{实际} = 5 × 60\% = 5 × 0.6 = 3kW$
    
    发电时间从9：00到16：00，共7小时。日发电量由 $W = Pt$ 计算：$W = 3 × 7 = 21kWh$
    
    因此，该日发电总量为21kWh。注意：实际光伏发电功率在一天中并非恒定，正午最高、早晚较低，60%是全天平均出力比例。(评分：计算实际平均功率得1分，写出 $W = Pt$ 并代入得1分，计算结果正确得1分。)
    
    <h3>(2) $节省电费 = W × 自用电价 = 21 × 0.52 = 10.92元$</h3>
    
    假设所发电量全部自用，每发1kWh就少从电网购买1kWh，因此节省的电费按自用电价计算：
    
    $节省电费 = W × 自用电价 = 21 × 0.52 = 10.92元$
    
    因此，该日节省电费10.92元。
    
    分析：如果采用“余电上网”模式，自用部分按0.52元/度节省，上网部分按0.42元/度获得收入，经济效益会略有不同。全部自用的经济性最优。(评分：判断按自用电价计算得1分，正确代入计算得1分，结果正确得1分。)
    
    <h3>(3) $3663\div 365 ≈ 10年$</h3>
    
    系统投资成本为40000元，每日节省10.92元。
    
    $投资回收天数 = 总投资/日节省 = 40000/10.92 ≈ 3663天$
    
    将天数换算为年：$3663\div 365 ≈ 10年$
    
    因此，大约需要10年回收投资成本。经济分析：家庭光伏系统的设计寿命一般为20\~25年，10年回收成本意味着后半段寿命期(约10\~15年)为纯收益期。
